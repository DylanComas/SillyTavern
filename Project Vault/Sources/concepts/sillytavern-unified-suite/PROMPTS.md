## Overview

All six boards were generated with the built-in image generator in the `ui-mockup` category. The three earlier Soft Bento Studio, Command Palette Minimal, and Pocket Tavern images were supplied as visual references.

Shared prompt: create a new shippable SillyTavern Studio design that combines modular bento cards, keyboard-first minimalism, and touch-friendly mobile ergonomics. Preserve real SillyTavern concepts. Use feasible HTML/CSS or Android-wrapper patterns, crisp typography, consistent line icons, and aligned light/dark variants of the same state. Light uses cool off-white and pale slate; dark uses near-black navy and elevated blue-gray. Cobalt indicates selection, mint indicates healthy state, coral identifies characters, and amber warns about context. Avoid glassmorphism, ornamental fantasy UI, device frames, watermarks, and unreadable filler.

1. **Desktop Conversation:** left navigation, conversation list, Seraphina chat with swipes and branches, contextual lore/generation/session cards, command bar, and persistent composer.
2. **Desktop Characters:** searchable portrait library plus complete tabbed character editor, linked lorebook, token estimate, recent chats, versions, import/export, and save actions.
3. **Desktop Lore:** lorebook list, structured entry editor, context budget, triggered entries, model/preset cards, and an open “Jump to anything” command palette.
4. **Android Conversation:** full mobile chat, swipe state, persistent composer and bottom navigation, with generation controls in a half-height bottom sheet.
5. **Android Characters:** filterable two-column portrait library with Seraphina selected and a quick-detail action sheet.
6. **Android Lore:** searchable lore list and compact entry editor with context budget, saved state, and a mobile “Jump to anything” command sheet.
