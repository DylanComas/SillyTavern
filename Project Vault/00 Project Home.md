## How the vault works

- Repository code and configuration remain authoritative in their original locations.
- Project documentation, decisions, plans, research, and working context live in this vault.
- `Sources/` contains generated document indexes from `ST-UI/sillytavern-ui-rework/` and `ST-UI/Concept Arts/` only.
- Each document's first heading is represented by its file under `Sources/`; the file acts as the document index.
- `Entries/` contains one generated note for every subordinate heading, including that heading's direct section text and hierarchy links.
- Every standalone locked concept receives its own populated subordinate heading and therefore its own entry note; parent notes carry a useful overview as well as child links.
- Update original source documents before synchronizing generated material.

SillyTavern's own documentation and the imported Memory Books and Summaryception extension documentation are intentionally excluded.
