# Generation prompt set

All ten images used the built-in image generator in the `ui-mockup` category. Shared direction: a high-fidelity, shippable SillyTavern fork interface; practical HTML/CSS-feasible controls; readable typography; straight-on app canvas; no watermark; no decorative sci-fi HUD; preserve real SillyTavern concepts such as characters, chats, lorebooks, personas, model/preset controls, context usage, swipes, branches, and the composer.

## 1. Obsidian Workbench

A 16:9 desktop interface inspired by modern developer tools and bento dashboards. Use a narrow navigation rail, central Seraphina conversation with swipe and message actions, and a right inspector for Model, Preset, Context, Sampling, and Lore Activity. Deep charcoal with restrained violet and cyan.

## 2. Storybook Editorial

A 16:9 warm editorial and digital-paper writing interface. Use a book-index library, manuscript-like conversation with chapter markers and branch controls, and a stationery-like composer with Continue, Impersonate, and Send. Ivory, oxblood, forest green, and subtle paper grain.

## 3. Immersive Glass Stage

A 16:9 background-forward chat over a dim rainy neon city. Use one central translucent chat column, a floating character dock, a restrained context drawer, and floating composer. Keep glass layers limited, readable, and achievable with normal CSS blur, borders, and shadows.

## 4. Soft Bento Studio

A 16:9 modular bento workspace. Include a conversation card, Seraphina state card, Active Lore, Generation, Branches, navigation rail, and composer. Use white cards on pale gray with cobalt, coral, and mint accents and a strict grid.

## 5. Command Palette Minimal

A 16:9 keyboard-first, distraction-free writing interface. Use a compact character/sidebar area, nearly borderless chat, contextual inspector, context meter, slash-command composer, and an open “Jump to anything” command palette for switching character, lorebook, model, branch, and focus mode.

## 6. Pocket Tavern

A portrait mobile PWA for one-handed use. Use large touch targets, compact avatar chat messages, a “2 of 4” swipe control, roomy composer, bottom navigation for Chats, Characters, Lore, Create, and More, plus an open generation bottom sheet. Midnight navy and warm amber.

## 7. Neo-Brutalist Character Lab

A 16:9 asymmetric but usable neo-brutalist layout with thick black borders, offset shadows, oversized typography, yellow character roster, white conversation, cobalt tools panel, and a large red Send action. Preserve conventional controls and a consistent grid.

## 8. Clarity Mode

A 16:9 accessibility-first high-contrast interface with large body type, generous line height, visible speaker labels, persistent labeled message actions, strong cyan focus outlines, and no translucent surfaces. Show a session panel with local model, connection, context, large font, and reduced motion states.

## 9. Branching Story Canvas

A 16:9 node-canvas interface for nonlinear conversation. Use an SVG/DOM-feasible branch graph with named story nodes, highlighted active path, minimap and zoom controls, plus a full live chat preview and composer on the right. Soft slate, off-white nodes, emerald active path, plum accent.

## 10. Cozy Tavern Desk

A 16:9 restrained skeuomorphic writing workspace. Use pinned index-card character portraits, a parchment-toned central chat sheet, and leather-tabbed Lorebook, Persona, and Scene Notes panels. Add only subtle wood, paper, and leather texture while retaining clear modern web controls.
